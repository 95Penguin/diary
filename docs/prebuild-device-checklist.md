# 构建前真机检查

每次准备长期自用或对外分发的安装包时，至少完整走一遍以下流程。

## 首次启动

- 冷启动后能直接看到时间轴，不会长时间停在启动图。
- “我的 → 关于拾时 → 本次启动耗时”三项均有数值。
- 切换浅色、夜间主题后，状态栏图标和页面文字清晰。
- 将字号调到“很大”，确认标题、按钮和设置说明没有截断。

## 记录与草稿

- 新建文字记录并保存；时间轴、日历和搜索均能找到。
- 添加图片、地点、标签和心情后保存，详情内容完整。
- 编辑到一半退出，在首页草稿箱中能继续编辑。
- 长按首页“＋”进入快速记录，保存后内容正常。
- 将记录移入回收站，再恢复；永久删除只出现在回收站。

## 地图与定位

- 自动定位能返回坐标、精度和地点名称。
- 地图选点、地点搜索、拖动图钉均可保存。
- 足迹地图能显示地点；加载失败时可重新加载或切换地点列表。
- “关于拾时 → 定位诊断”显示地图密钥已注入、地图服务可访问。
- 若底图为空，复制应用包名，并核对高德控制台的包名、发布版 SHA-1 和 Android Key。

## 管理与隐私

- 批量修改标签、地点和收藏后，时间轴结果正确。
- 地点合并、别名和旧记录补点不会产生重复地点。
- 切换精确、模糊、仅名称三种地点隐私方式，各新建一条记录检查结果。
- 可阅读导出隐藏地点时，Markdown 和 HTML 中不包含地点名称。

## 备份与恢复

- 导出完整备份后运行健康检查，结果为“完整可恢复”。
- 恢复前预览能显示记录、媒体、版本和个人资料。
- 用一份临时测试数据执行恢复，确认记录、图片、昵称、签名和设置可用。
- 已设置固定目录时，手动备份和每日自动备份均不会阻塞启动。

## 最后检查

```bash
npx tsc --noEmit
npm run lint
npm run test:data
npm run version:check
```

确认没有失败项后，再运行对应的 EAS 构建命令。
