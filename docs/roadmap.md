# 拾时未来路线

拾时继续坚持本地优先、私人使用和长久可迁移。以下功能按“先让已有记录更好看，再增加新的记录方式”推进，具体版本不预先绑定。

## 1. 媒体浏览（首版已完成）

- 按年月集中浏览记录与后续中的图片、视频
- 支持全部、图片、视频筛选和全屏预览
- 可从媒体直接返回所属记录
- 后续可增加月份快速定位、实况照片播放与媒体缺失检查

## 2. 分享卡片（首版已完成）

- 将单条记录生成干净的图片卡片
- 可选择日期、正文、图片、地点等展示范围
- 默认隐藏隐私信息，不引入公开社区或社交关系

## 3. 年度回顾（首版已完成）

- 汇总某年的记录天数、文字、图片、地点、心情和高频标签
- 从月份与四季中挑选可回看的代表时刻
- 回顾结果由本地数据生成，可导出但不会上传分析

## 4. 数据与备份体检（首版已完成）

- 检查最近备份时间、备份完整性、媒体缺失与数据库状态
- 给出可执行的修复建议，而不是只展示技术错误
- 重要操作前提示先生成一份可恢复备份

## 5. 时间胶囊（首版已完成）

- 写下内容并指定未来可开启时间，到期前隐藏正文
- 状态依次为“未到期”“可开启”“已开启”
- 开启后永久保存在时间胶囊页的“已开启”档案中，可以随时重新阅读
- 开启后的回应保存在胶囊下方，也可以在以后被“拾起一刻”温和地再次带回
- 不自动复制到普通时间轴，避免产生重复记录；未来可提供“保存为普通记录”的主动操作
- 胶囊、媒体、开启时间、开启状态和回应都进入完整备份

当前已完成胶囊文字与图片/视频的创建、系统日期时间选择、封存确认、锁定、到期自动刷新、开启、再次阅读、媒体滑动预览、本地到期通知、开启后回应、30 天回收站，以及包含媒体文件的 ZIP 完整备份恢复。

## 当前状态

五项路线功能的首版均已完成并归入 `1.0.6`。本版发布后暂停扩展新功能，优先根据长期真机使用结果处理稳定性、兼容性和界面细节。
